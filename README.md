## 一、程式用途與執行方式

### 程式用途
本程式用於處理朋友聚餐的費用計算，包含以下功能：
1. **資料清理**：清理聚餐名稱的頭尾空白並轉為小寫；移除餐費字串中的 `NT$`、逗號與空白並轉為浮點數（float）。
2. **型別轉換**：將字串格式的人數轉換為整數（int）。
3. **費用計算**：依原始餐費計算 10% 服務費，再扣除折價券計算應付總額與每人分攤費用。
4. **預算比對**：判斷每人分攤費用是否超過每人預算（300 元），並產生布林值（bool）。

### 執行方式
1. 將本儲存庫中的 `dinner_split_學號.ipynb` 下載或上傳至 [Google Colab](https://colab.research.google.com/)。
2. 點選選單列的 **「執行階段」>「全部執行」**（或按快捷鍵 `Ctrl + F9`），即可依序執行三組測試區塊並觀看列印結果。

## 三、個人問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
**回答：**
在 Python 中，`"4"` 是字串型態（`str`），而餐費計算出來的應付總額是數值型態（`float`）。Python 不支援將數字直接除以字串（會引發 `TypeError` 錯誤）。必須透過 `int("4")` 將其轉換為整數 `4` 後，才能進行數學除法運算以算出每人費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**回答：**
若先扣除折價券：
1. **折扣後餐費**：$1,200 - 100 = 1,100$ 元
2. **服務費**：$1,100 \times 10\% = 110$ 元
3. **應付總額**：$1,100 + 110 = 1,210$ 元

這與題目規定的 $1,220$ 元不同，因為計費順序改變導致服務費的計算基準變少。題目規定服務費必須以「原始餐費（1,200 元）」計算（服務費為 120 元）；若先扣折價券，服務費的計算基準減少了 100 元，連帶使服務費少收了 $100 \times 10\% = 10$ 元，因此應付總額會減少 10 元。
